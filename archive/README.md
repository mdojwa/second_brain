# 🗄️ archive/

Closed, shipped or cancelled material moved out of the core files, so `BRAIN.md`/`TASKS.md` stay small.

```
archive/YYYY-MM-DD-what-it-is.md
```

## Rules

- Move an item here **in the same session** it closes, and leave a one-line pointer under `TASKS.md` → "Completed".
- **Lose nothing**: make sure the content is here *before* trimming it from the core file.
- Read `archive/` only when someone explicitly asks about history.
